# unityroom ゲーム紹介文

2026-09-18の改稿案。変更点は3つ: (1) 「限界を越えても一瞬は爆発しない。その隙間で離す」という核心を前に出す (2) ランキングの2つの遊び方を1文ずつに分ける (3) 8500などの内部の数字は紹介文から外し、ゲーム内の表示(離した後の「あと何秒」「OVER THE EDGE」)に任せる。あわせて、離した後の表示とタイトルのデモを案内する。

## 本文(コピー用)

```
画面を長押しすると、まわりの粒子が集まってきます。
集まるほどスコアが上がりますが、集まりすぎるとビッグバンが起きて、そのラウンドは0点。
限界を越えても、ほんの一瞬だけは爆発しません。その隙間で離すのが、このゲームの「Edge」です。

【ランキング】
・スコア:ぎりぎりまで粘って、高得点を狙います。
・ビッグバンまでの時間:わざと爆発させて、最短を狙う遊び方です。

【操作】
・PC:マウスの左クリックを長押し。押したまま動かすと、集める位置が変わります。離すと確定。
・スマホ:画面を長押し(粒子は指の少し上に集まります)。
・右上のボタンとスライダーで、ミュートと音量を変えられます。

【ヒント】
・画面の端では粒子が届かず、ビッグバンまで届きません。
・上の危険度バー、警告音、背景の星のゆがみが目安になります。
・離した後に「あと何秒で爆発していたか」が出ます。次のラウンドの目安にしてください。
・タイトル画面の右下で、お手本のデモが見られます。

【クレジット】
フォント:BIZ UDゴシック(SIL Open Font License 1.1)
```
