# モデル実験ログ

Brain(Claude Code)がタスクをagy/discord-ai-hubに委任した際の記録。「どれだけタスクをClaude Codeから分散させられるか」という本プロジェクトの実験目的の一部として、モデル・effort別の成否と選択理由を都度残す。

## 運用ルール

- 委任前: 類似タスクが既にあれば下表を確認し、それを踏まえてモデル・effortを選ぶ。
- 委任後: 結果が出たら都度1行追記する(後回しにしない)。
- 統計的な自動集計(成功率の自動計算等)は今回は導入しない。必要になったら別途検討する(2026-09-10、ユーザー判断)。ログが溜まったら、傾向を`docs/workflow.md`に手動で蒸留し直す。
